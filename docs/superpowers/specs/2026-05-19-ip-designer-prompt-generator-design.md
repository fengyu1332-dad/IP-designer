## 1. 产品概述

### 1.1 产品定位

基于 LLM 的自动化内容创作工具，通过结构化收集用户当下的环境与心境参数，自动生成具备高度共情力的"金句"以及专业级别的 AI 绘画 Prompt。

### 1.2 目标用户

个人 IP 创作者，需要高频次在社交媒体发布高质量图文内容的用户。

### 1.3 核心价值

- 极简化操作：用户仅需选择参数，点击生成
- 高质量输出：结合情绪与场景，生成共情力强的文案和专业 Prompt
- 即时可用：一键复制生成结果，快速分发

## 3. 功能模块

### 3.1 模块一：环境参数配置 (Input Module)

#### 日期与节假日
- 默认读取系统当前时间（年/月/日/星期）
- 显示格式：`2026年5月19日 周二`
- 支持手动选择（日期选择器）

#### 天气与光影
- 标签选择（单选）
- 选项：`晴天`、`晨光`、`阴雨`、`大雾`、`暮色`、`星空`
- 选中状态：渐变背景色 + 白色文字

#### 情绪状态
- 标签选择（单选）
- 选项：`平静`、`充满干劲`、`焦虑反思`、`感恩`、`疲惫但充实`、`松弛感`
- 选中状态：渐变背景色 + 白色文字

### 3.2 模块二：主题意图选择 (Theme Selection Module)

#### 交互设计
- 一级分类：Tab 切换布局
- 二级分类：网格卡片布局

#### 一级分类列表
| 分类 | 视觉风格要求 |
|------|-------------|
| 硬核爱好与探索 | 强调"实操性"与"工具感" |
| 家庭责任与陪伴 | 弱化面部特写，强调整体氛围 |
| 日常烟火与碎片 | "抓拍感"和粗糙的真实颗粒感 |
| 认知觉醒与感悟 | 大量留白，极简或意境感 |
| 人文关怀与共情 | 纪实感，光影对比强烈 |
| 职业信念与长期主义 | 稳重、专业，时间沉淀的厚重感 |

#### 二级分类选项（示例）

**职业信念与长期主义** 的二级选项：
- 晨光中提包前行的背影
- 深夜复盘的办公桌
- 行业大会上专注听讲的侧影
- 多年与客户的合影对比
- 被反复修改的商业计划书
- 解决复杂技术难题的草稿

### 3.3 模块三：LLM 处理引擎 (Processing Engine)

#### 调用流程

```
用户点击生成 → 打包参数 → 调用 LLM API → 解析 JSON 响应 → 更新 UI
```

#### 请求 Payload
```json
{
  "context": {
    "date": "2026-05-19",
    "weather": "晨光",
    "mood": "充满干劲"
  },
  "theme": {
    "primary": "职业信念与长期主义",
    "secondary": "深夜复盘的办公桌"
  }
}
```

#### LLM System Prompt
```
# Role
你是一个顶级的社交媒体内容总监与 AI 视觉提示词（Prompt）专家。

# Objective
根据用户提供的环境参数和特定主题，创作一句极具共情力、适合作为配图文字的中文金句，并配套生成一段极其专业、细节丰富的英文 AI 绘图 Prompt。

# Input Parameters
- 日期/节气：{Date}
- 天气/光影：{Weather}
- 当前情绪：{Mood}
- 核心主题：{Category} -> {Sub-option}

# Workflow
1. 分析输入参数，寻找环境、情绪与核心主题之间的内在联系与张力。
2. 撰写中文金句：字数限制在 15-30 字。风格需深刻、克制、真实。
3. 构建英文 Prompt：
   - 必须使用英文
   - 结构：主体描述、背景环境、光影设置、摄影机视角、画面风格
   - 结尾加上宽高比参数 `--ar 3:4` 或 `--ar 16:9`

# Output Format (Strict JSON)
{
  "quote": "生成的中文金句",
  "image_prompt": "生成的英文绘图 Prompt"
}
```

#### 响应 Payload
```json
{
  "status": "success",
  "data": {
    "quote": "时间会筛选出真正有耐心的人，契约的重量在于几十年如一日的托付。",
    "image_prompt": "A back view of a professional walking forward in the soft, golden morning light. The person is holding a thick leather briefcase. Urban street environment, cinematic lighting, volumetric light rays passing through buildings, 50mm lens, shallow depth of field, documentary photography style, high quality, 8k --ar 3:4"
  }
}
```

### 3.4 模块四：结果展示与交互 (Output Display)

#### 金句展示区
- 白色卡片容器
- 大字号引用文字（20px+）
- 一键复制按钮（右上角）

#### Prompt 展示区
- 深色背景卡片（Slate-900）
- 等宽字体代码块
- 一键复制按钮（右上角）

#### 重新生成按钮
- 位于结果区底部
- 居中显示
- 重新调用 LLM，生成不同内容

### 3.5 API Key 管理

#### 存储策略
- 使用 localStorage 存储加密后的 API Key
- 首次使用弹出设置面板
- 支持随时修改

#### 设置面板
- API Key 输入框（密码类型）
- Provider 选择（OpenAI / Claude / 自定义）
- Endpoint URL（用于兼容格式）
- 保存/取消按钮

## 4. UI 设计规范

### 4.1 视觉风格

**设计理念**：极简纯净
- 大量留白，克制克制再克制
- 契合"言之有物、深刻真实"的调性
- 避免花哨装饰，突出内容本身

### 4.2 色彩系统

| 用途 | 色值 |
|------|------|
| 主色渐变 | `#667eea` → `#764ba2` (Violet to Purple) |
| 背景色 | `#f8fafc` (Slate-50) |
| 卡片背景 | `#ffffff` (White) |
| 深色卡片 | `#0f172a` (Slate-900) |
| 文字主色 | `#1e293b` (Slate-800) |
| 文字次色 | `#64748b` (Slate-500) |
| 边框色 | `#e2e8f0` (Slate-200) |

### 4.3 间距系统

- 页面最大宽度：`max-w-4xl` (896px)
- 区块间距：`mb-12` (48px)
- 卡片内边距：`p-6` (24px)
- 元素间距：`gap-2` / `gap-3` / `gap-4`

### 4.4 圆角系统

| 组件 | 圆角 |
|------|------|
| 按钮/标签 | `rounded-xl` (12px) |
| 卡片 | `rounded-2xl` (16px) |
| 大容器 | `rounded-3xl` (24px) |

### 4.5 动效设计

| 动效 | 参数 |
|------|------|
| 淡入动画 | `fade-in 0.5s ease-out` |
| 标签悬停 | `translateY(-2px)` |
| 按钮过渡 | `transition-all 0.2s` |

## 6. 错误处理

### 6.1 API 调用错误

| 错误类型 | 处理方式 |
|---------|---------|
| 无 API Key | 弹出设置面板提示用户配置 |
| 网络错误 | Toast 提示"网络连接失败，请重试" |
| API 限流 | Toast 提示"请求过于频繁，请稍后再试" |
| API 错误 | Toast 提示具体错误信息 |

### 6.2 参数校验

- 必须选择：天气、情绪、主题（二级）
- 未选择时对应按钮禁用状态
